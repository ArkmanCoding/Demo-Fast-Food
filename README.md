## 🇮🇷 درباره پروژه

**منو فست فود نه تاب دونر** یک منوی دیجیتال مدرن و واکنش‌گراست که برای نمایش حرفه‌ای محصولات فست‌فود طراحی شده است.

هدف پروژه، ایجاد تجربه‌ای سریع، ساده و جذاب برای مشتریان است؛ به‌طوری‌که کاربر بتواند محصولات را مشاهده کند، بین دسته‌بندی‌ها جست‌وجو کند و آیتم‌های موردنظر خود را به سبد خرید اضافه نماید.

این پروژه به‌عنوان یک نمونه‌ی اولیه‌ی حرفه‌ای برای ارائه به رستوران‌ها، فست‌فودها و کسب‌وکارهای غذایی توسعه داده شده است.

---

## 🇬🇧 About The Project

**Na Taab Doner Fast Food Menu** is a modern and responsive digital menu designed for fast-food businesses.

The project focuses on delivering a fast, clean, and user-friendly experience. Customers can browse food items, filter products by category, search through the menu, and add products to a shopping cart.

This project was developed as a professional MVP for restaurants, fast-food shops, and food businesses that need a modern digital menu solution.
